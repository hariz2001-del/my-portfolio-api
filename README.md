# My Portfolio API

A simple public Express API for the portfolio website.

## Getting started

```bash
npm install
npm run dev
```

The API will run on:

- http://localhost:5000

## Available endpoints

- GET `/api/health`
- GET `/api/profile`
- GET `/api/about`
- GET `/api/skills`
- GET `/api/projects`
- GET `/api/contact`
- GET `/api`

## Notes

This is intentionally public and has no authentication yet.
